# TPL 학생별 성적 분석·오답 리포트 사이트

첨부된 **1회·2회·3회·4회·5회·6회·7회·8회·9회·10회 시험지와 공식 해설**을 기준으로 제작한 GitHub Pages용 웹사이트입니다. 교사가 학생의 학교, 이름, 1~20번 답안을 입력하면 자동 채점한 뒤 학생마다 서로 다른 결과 링크를 생성합니다.

## 구현된 기능

- 20문항 자동 채점: 정답 `+5점`, 오답 `-1.25점`, 미기입 `0점`, 100점 만점
- 학생마다 서로 다른 전용 성적표 링크 생성
- 전체 평균·중앙값·최고점·석차·상위 비율·점수 분포 그래프
- 문항별 대단원·세부 단원·학생 답·정답·정오·배점·전체 정답률
- 단원별 학생 정답률과 전체 평균 비교 그래프
- 같은 학교·이름의 이전 회차 점수 추세, 강점·취약점, 자동 코멘트
- 오답·미기입 문항마다 원문 이미지, 핵심 해설, 필요한 공식, 같은 풀이 방식의 5지선다 동형 문제 1개
- 동형 문제의 정답·해설은 처음에 숨김 → 학생이 선택지를 고르는 즉시 정오·정답·해설 공개 → 다시 풀기로 초기화
- 학생별 동형 문제 풀이 상태를 해당 기기 브라우저에 자동 저장
- 결과 페이지 오른쪽 위의 링크 복사, Word 저장, PDF 저장·인쇄 버튼
- 학생 기록 검색·수정·삭제, CSV 내보내기, JSON 백업·복원, CSV 일괄 가져오기
- 엑셀·Google Sheets에서 답안 한 행을 붙여넣을 때 빈 셀의 문항 위치까지 정확히 보존
- 스마트폰·태블릿·PC 반응형 화면과 A4 인쇄 스타일
- 선택형 Google Sheets 누적 저장과 무작위 토큰 기반 학생 링크
- Apps Script URL을 브라우저에 영구 저장하고 다음 접속부터 자동 재연결, 다른 기기용 설정 링크 제공
- WRITE_KEY를 교사 기기에 한 번 저장하여 제출 때마다 다시 묻지 않음
- 이전 회차를 나중에 입력해도 기존 상위 회차 서버 링크가 최신 이력으로 자동 갱신
- 교사용 학생 목록을 Google Sheets에서 자동 동기화하여 다른 컴퓨터에서도 같은 기록 확인
- 기존 브라우저에만 남은 기록을 버튼 한 번으로 Google Sheets에 이전

현재 **1회~10회 시험·해설·문항 이미지·동형 문제**와 **1회~5회 학생 결과 225개**가 등록되어 있습니다. 6회~10회는 학생 정오표가 제공되지 않아 시험 자료만 추가했으며, 교사용 화면에서 새 답안을 입력할 수 있습니다. 학교와 이름이 같은 학생은 이전 회차 결과까지 자동으로 연결되어 누적 추세와 강점·취약점 분석에 반영됩니다.

## Young's Physics 공식 로고 테마

업로드된 **Young's Physics 로고 원본**을 실제 사이트 자산으로 포함하고, 단순 미리보기 이미지가 아니라 GitHub Pages에서 실행되는 교사용 입력 화면·학생 리포트·사용 안내 화면 전체에 적용했습니다.

- 흰색 상단 헤더에 공식 가로형 로고 사용
- 로고의 진한 남색과 선명한 파란색을 기준으로 전체 색상 체계 통일
- 데스크톱에서 교사용·학생용 좌측 사이드바 제공
- 원자 궤도 모티프를 히어로 카드와 사이드바 배경에 적용
- 학생 리포트 상단에 학생 정보·총점·정답률·전체 평균을 한눈에 보이는 대시보드 카드로 구성
- PDF·Word·링크 복사 버튼을 상단 오른쪽에 유지
- 모바일에서는 사이드바와 메뉴를 자동 축약하고 가로 넘침 없이 표시
- 인쇄와 Word 출력에서도 공식 로고와 새 테마가 유지되도록 구성

## 로컬에서 확인하기

`index.html`을 파일로 직접 열기보다 정적 서버를 사용하는 것이 안전합니다. 프로젝트 루트에서 실행합니다.

```bash
python -m http.server 8000 --directory site
```

브라우저에서 `http://localhost:8000`을 엽니다. 입력 화면의 **예시 입력** 버튼으로 전체 흐름을 바로 확인할 수 있습니다.

## GitHub Pages에 배포하기

1. GitHub에서 새 저장소를 만듭니다.
2. 압축을 푼 프로젝트의 `.github`, `apps-script`, `site`, `tests`, `README.md` 등을 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 지정합니다.
4. `main` 또는 `master` 브랜치에 커밋하면 `Deploy TPL Score Report to GitHub Pages` 워크플로가 실행됩니다.
5. **Actions** 탭에서 배포가 완료되면 표시되는 Pages 주소로 접속합니다.

워크플로는 `site/` 폴더만 게시합니다. 따라서 `apps-script/`, `tests/`, `sample-data/`는 Pages 산출물에 포함되지 않지만, **이번 버전은 기존 성적을 바로 불러오기 위해 `site/assets/seed-records.js`와 회차별 CSV에 실제 학생 이름·답안을 포함**합니다. 공개 Pages에 배포하면 이 파일도 누구나 내려받을 수 있으므로, 실제 운영에서는 비공개 배포 환경을 사용하거나 기본 데이터를 제거하고 Google Sheets 모드로 이전하세요.

## 저장 방식 1: 브라우저 임시 캐시

현재 배포 설정에서는 학생 정보를 여러 컴퓨터에서 확인할 수 있도록 **Google Sheets + Apps Script 저장이 기본이자 필수 방식**입니다. 브라우저 `localStorage`는 화면을 빠르게 표시하기 위한 임시 캐시와 기존 데이터 이전 용도로만 사용합니다.

- 학생 제출이 성공하려면 Apps Script 서버 저장이 먼저 완료되어야 합니다.
- 서버 저장에 실패하면 완료 기록과 학생 링크를 만들지 않습니다.
- 이전 버전에서 브라우저에만 저장된 기록은 학생 기록 영역의 **이 기기 기록 서버로 올리기** 버튼으로 이전할 수 있습니다.
- 엑셀에서 `1\t\t4...`처럼 복사한 탭 구분 답안은 빈 셀도 문항 위치로 유지됩니다.

## 저장 방식 2: Google Sheets + Apps Script

여러 기기에서 입력하거나 학생 링크를 짧게 유지하고 누적 통계를 서버에서 계산하려면 이 모드를 사용합니다.

### Apps Script 설치

1. 빈 Google Sheet를 만듭니다.
2. **확장 프로그램 → Apps Script**를 엽니다.
3. `apps-script/Code.gs` 전체를 붙여넣습니다.
4. Apps Script 왼쪽 **프로젝트 설정 → 스크립트 속성**에 다음 값을 추가합니다.
   - `WRITE_KEY` — 교사만 아는 충분히 긴 저장·삭제 비밀번호. 필수입니다.
   - `SPREADSHEET_ID` — 시트에 연결된 스크립트라면 생략할 수 있습니다. 독립형 스크립트라면 대상 Sheet URL의 `/d/`와 `/edit` 사이 ID를 입력합니다.
5. 편집기에서 `initializeSheet` 함수를 한 번 실행하고 권한을 승인합니다.
6. **배포 → 새 배포 → 웹 앱**을 선택합니다.
   - 실행 사용자: **나(배포한 사용자)**
   - 액세스 권한: 학생 링크를 로그인 없이 열어야 한다면 **모든 사용자·익명 사용자 포함**
7. 배포된 `/exec` URL을 입력 화면의 **누적 저장 방식 설정**에 입력합니다.
8. **주소 저장·연결 확인**을 누르고 같은 설정 영역의 **Google Sheets 저장 키**에 `WRITE_KEY`를 한 번 입력합니다. `/exec` URL, 저장 방식, 키는 해당 교사 기기의 브라우저에 유지되어 이후 제출 때 팝업이 다시 나타나지 않습니다. 공용 컴퓨터에서는 작업 후 **저장 키 지우기**를 누르세요.
9. 다른 기기는 교사용 화면의 **다른 기기 설정 링크 복사**를 이용하거나, `site/assets/config.js`의 `backendUrl`에 `/exec` 주소를 넣어 모든 기기의 기본 연결로 지정합니다. `WRITE_KEY`는 절대로 GitHub 코드에 넣지 않습니다.

상세 안내는 `apps-script/README.md`에 있습니다.

### 교사 기기 간 학생 기록 동기화

- 사이트를 열면 Apps Script 연결을 확인한 뒤 Google Sheets의 학생 기록을 자동으로 내려받습니다.
- 새 컴퓨터에서는 보안을 위해 `WRITE_KEY`를 **처음 한 번만** 입력해야 하며, 이후에는 해당 브라우저에 유지됩니다.
- 학생 기록 영역의 **서버 기록 새로고침** 버튼으로 즉시 최신 목록을 불러올 수 있습니다.
- 페이지를 다시 활성화하거나 일정 시간이 지나면 자동 동기화됩니다.
- Google Sheets에서 삭제된 서버 기록은 다음 완전 동기화 때 해당 기기의 서버 캐시에서도 제거됩니다.
- `WRITE_KEY`는 학생 링크와 GitHub 코드에 포함되지 않으며, 학생은 키 없이 자신의 무작위 토큰 링크를 열 수 있습니다.

### 서버 모드 동작

- 학생 결과 링크에는 Apps Script 주소와 무작위 결과 토큰만 들어갑니다. 이름·학교·답안은 URL에 직접 포함하지 않습니다.
- 링크를 연 시점의 동일 시험 누적 평균, 문항별 정답률, 분포를 Google Sheet에서 다시 계산합니다.
- 같은 **학교 + 학생 이름 + 시험**을 다시 저장하면 기존 행과 토큰을 유지한 채 답안을 갱신합니다.
- 같은 **학교 + 학생 이름**의 다른 회차 기록은 입력 시점이 아니라 회차 번호 순으로 연결합니다. 예를 들어 5회를 먼저 저장한 뒤 4회를 추가해도 기존 5회 링크를 다시 열거나 **최신 분석**을 누르면 4회가 자동 반영됩니다. 4회 성적표에는 미래 회차인 5회가 표시되지 않습니다.
- 기존 `#report=...` 정적 링크 안에 서버 토큰이 남아 있으면 새 버전에서 자동으로 동적 `#id=...` 링크로 전환됩니다.
- 학생 링크를 가진 사람은 해당 토큰의 결과를 볼 수 있습니다. 토큰은 로그인 비밀번호가 아니라 소지자 링크이므로 공개 게시판에 올리지 마세요.
- 관리자 화면에서 서버 기록이 연결된 학생을 삭제하면 `WRITE_KEY` 확인 후 Google Sheet 기록도 함께 삭제됩니다.

Google Workspace 정책상 익명 웹 앱 배포를 허용하지 않는 조직에서는 브라우저 모드를 사용하거나 조직의 인증 정책에 맞는 별도 백엔드를 구성해야 합니다.

## 동형 문제 풀이 방식

- 학생에게는 틀리거나 비운 문항마다 원문과 다른 조건의 5지선다형 동형 문제가 정확히 1개씩 표시됩니다.
- 정답과 해설은 문제를 처음 보여 줄 때에는 가려져 있습니다.
- 학생이 ①~⑤ 중 하나를 고르는 순간 바로 채점되며, 고른 답의 정오와 올바른 정답, 같은 풀이 방식, 전체 해설이 함께 표시됩니다.
- 정답 공개 전에는 **힌트 보기**를 사용할 수 있고, 공개 후에는 **다시 풀기**로 선택·채점·해설 공개 상태를 모두 초기화할 수 있습니다.
- 풀이 상태는 학생이 보고 있는 기기의 브라우저에 저장되며 다른 기기에는 자동 동기화되지 않습니다.
- 동형 문제는 첨부 시험지의 공식 문항이 아니라, 각 원문 문항의 개념과 풀이 구조를 기준으로 새로 제작한 학습용 문항입니다.

## Word와 PDF 저장

- **Word 저장**: 결과 페이지, 원문 문제 이미지, 동형 문제의 정답과 풀이를 포함한 Word 호환 `.doc` 파일을 생성합니다.
- **PDF·인쇄**: 브라우저 인쇄 창을 열며, 프린터 선택에서 **PDF로 저장**을 선택합니다. 인쇄본에는 동형 문제의 정답과 풀이가 함께 표시됩니다.
- 인쇄 시 상단 도구 버튼은 자동으로 숨겨지고 A4 기준 페이지 구분이 적용됩니다.

## 7번 해설 교정 메모

7번의 보기 ㄴ은 유도 전류가 **시계 반대 방향**이라고 되어 있고 공식 정답표는 **⑤**입니다. 그림에서 막대가 아래로 이동하면 회로 면적과 지면 밖 방향 자기선속이 감소하므로, 렌츠 법칙에 따라 지면 밖 방향 자기장을 만드는 **시계 반대 방향 전류**가 흐릅니다. 따라서 사이트는 ⑤로 채점합니다.

첨부 해설 본문의 ‘시계 방향’ 문구는 그림·보기·공식 정답표와 맞지 않는 오기로 판단하여, 사이트의 해당 문항에 교정 메모를 표시했습니다.

## 답안 키보드 입력 방식

기존의 문항별 선택 버튼 방식 외에, 이번 버전부터 교사용 학생 답안 입력 영역을 **키보드 입력 중심**으로 바꾸었습니다.

- 1~20번 각 문항 칸에 숫자 `1`~`5`를 직접 입력합니다.
- 답을 입력하면 다음 문항으로 자동 이동합니다.
- `0`, `x`, `X`, `-`, 공백은 미기입으로 처리합니다.
- 한 줄 붙여넣기에서도 `0`, `X`, `-`를 미기입으로 안전하게 인식하며, 하이픈 앞의 답안이 문항 번호로 오인되어 누락되지 않도록 입력 파서를 보완했습니다.
- 각 문항의 **비우기** 버튼으로 해당 답만 지울 수 있습니다.
- 방향키, Enter, Backspace로 문항 사이를 이동할 수 있습니다.
- 20개 답안을 한 줄로 복사해 첫 칸에 붙여넣으면 1~20번에 자동 분배됩니다. 예: `43241455421353443315`
- 기존의 한 줄 답안 붙여넣기와 CSV 일괄 가져오기는 그대로 유지됩니다.

## Word 리포트

성적 리포트의 **Word 저장** 버튼은 단순 HTML 파일이 아니라 실제 `.docx` 문서를 생성합니다. 문서에는 로고, 전체 성적 비교·점수 분포·대단원 비교·이전 회차 추세 그래프, 문항별 정오표, 모든 오답·미기입 원문 이미지, 해설·필요 공식·확인할 점과 동형 문제 정답·풀이가 포함됩니다. 원문 WebP 이미지는 Word 호환성을 위해 JPEG로 변환해 문서 내부에 삽입하므로 인터넷 연결 없이도 그림이 유지됩니다.
