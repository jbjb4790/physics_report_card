# Young's Physics TPL 성적 분석 사이트 — 공개 배포 안전본

GitHub Pages에 바로 배포할 수 있도록 정리한 1회~10회 통합 프로젝트입니다.

## 포함 기능

- 1회~10회 시험지·해설·정답·문항 이미지
- 정답 +5점, 오답 -1.25점, 미기입 0점 자동 채점
- 학생별 고유 성적표 링크
- 전체 성적 비교, 문항별·단원별 분석, 이전 회차 추세
- 오답 해설·공식과 같은 풀이 방식의 동형 문제
- 동형 문제 선택 전 정답 숨김, 선택 즉시 정답·해설 공개
- PDF·인쇄 및 고화질 Word(.docx) 출력 — 로고, 성적 그래프, 문항별 정오표, 오답 원문 이미지, 해설·공식·동형 문제까지 문서 안에 직접 삽입
- 문항별 키보드 입력, 엑셀 빈 셀까지 보존하는 탭 붙여넣기, CSV 가져오기
- 선택형 Google Sheets + Apps Script 누적 저장
- Apps Script URL 브라우저 영구 저장·자동 재연결·다른 기기 설정 링크
- 교사용 WRITE_KEY를 이 기기에 한 번 저장하여 제출 때마다 재입력하지 않는 기능
- 이전 회차를 나중에 입력해도 기존 상위 회차 링크가 최신 이력으로 자동 갱신되는 기능

## 개인정보 보호 상태

이 버전에는 실제 학생 이름과 답안이 들어 있지 않습니다.

- `site/assets/seed-records.js`는 빈 배열입니다.
- 1회~5회 실제 학생 데이터 CSV는 제거했습니다.
- `sample-data/`에는 가상의 예시와 빈 입력 양식만 있습니다.

교사용 화면에서 새 학생을 직접 입력할 수 있으며, 브라우저 저장 또는 `apps-script/`의 Google Sheets 저장 방식을 사용할 수 있습니다.

## GitHub Pages 배포

1. 이 폴더의 내용 전체를 GitHub 저장소 최상위에 올립니다.
2. `.github/workflows/pages.yml`과 `site/`가 저장소 루트에 있어야 합니다.
3. **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
4. `main` 또는 `master` 브랜치에 커밋하면 `site/` 폴더가 자동 배포됩니다.

ZIP 파일 자체를 GitHub에 한 파일로 올리지 말고, 압축을 푼 뒤 내부 파일 전체를 업로드하세요.

## Google Sheets 누적 저장

`apps-script/README.md` 순서에 따라 `Code.gs`를 Apps Script에 배포한 뒤 사이트의 누적 저장 방식 설정에 웹 앱 URL을 입력합니다. 연결에 성공한 URL은 같은 브라우저에 계속 저장되고 다음 접속부터 자동 연결됩니다. 다른 기기에서는 사이트의 **다른 기기 설정 링크 복사** 기능을 사용하거나 `site/assets/config.js`의 `backendUrl`에 `/exec` 주소를 넣어 전체 배포의 기본 연결로 지정할 수 있습니다. `WRITE_KEY`는 GitHub 코드에 적지 않습니다. 교사용 화면의 누적 저장 방식 설정에서 한 번 입력하면 해당 교사 기기의 브라우저에 저장되어 이후 제출 때 다시 묻지 않습니다. 공용 기기에서는 작업 후 저장 키를 지우세요.

학생 링크가 `#id=...` 형태의 Apps Script 토큰 링크라면 열 때마다 Google Sheet에서 이력을 다시 계산합니다. 따라서 5회 성적을 먼저 저장한 뒤 4회 성적을 추가해도 기존 5회 링크를 다시 열거나 **최신 분석**을 누르면 4회가 이전 회차 분석에 포함됩니다. 예전에 만들어진 `#report=...` 형태의 링크라도 내부에 Apps Script 토큰이 들어 있으면 이번 버전에서 자동으로 `#id=...` 서버 링크로 전환됩니다. 토큰이 전혀 없는 순수 브라우저 백업 링크만 한 번 다시 저장하여 서버 링크를 발급해야 합니다.


## Word 리포트

성적 리포트의 **Word(.docx) 저장** 버튼은 현재 브라우저에 표시된 Young's Physics 리포트 디자인을 A4 고화질 페이지로 다시 그린 뒤, 각 페이지를 실제 `.docx` 파일 안에 직접 삽입합니다. 따라서 로고 테마, 점수 카드, 전체 성적 비교·점수 분포·대단원 비교·이전 회차 추세 그래프, 문항별 정오표, 모든 오답·미기입 원문 이미지, 해설·필요 공식·동형 문제와 정답·풀이가 화면과 같은 배치로 보입니다.

WebP 문제 이미지, SVG 그래프, 로고와 배경 장식은 Word가 외부 주소에서 불러오는 방식이 아니라 브라우저에서 PNG 페이지로 변환되어 문서 내부에 내장됩니다. 다른 컴퓨터나 인터넷이 없는 상태에서도 그림이 깨지지 않습니다. 화면형 변환이 브라우저 환경 때문에 실패하는 경우에는 자동으로 구조형 `.docx` 생성 방식으로 전환합니다. 화면과 동일한 모양을 우선하기 때문에 Word 안의 본문은 페이지 이미지 형태이며, 텍스트를 직접 편집해야 할 때에는 PDF·인쇄 대신 웹 화면에서 내용을 복사하는 방식이 적합합니다.

## 학교 입력 생략

학교 입력은 선택 사항입니다. 교사용 입력 화면, CSV/JSON 가져오기, Apps Script 저장에서 학교 값이 비어 있으면 자동으로 `미입력`으로 저장됩니다. 동일 이름 학생의 회차 연결은 `학교 + 이름`을 기준으로 하므로 학교를 생략한 동명이인은 같은 학생으로 연결될 수 있습니다.


## v3.0.0 · 동일 시험 전체 통계 자동 반영

학생 결과를 새로 저장할 때 같은 시험의 기존 학생 기록이 이 기기에만 있거나 기본 데이터로 들어 있는 경우, 해당 기록을 먼저 Google Sheets에 자동 반영한 뒤 현재 학생을 저장합니다. 서버가 반환한 비교 인원이 이 기기의 동일 시험 기록 수보다 적으면 한 번 전체 재동기화하고 다시 계산합니다. 따라서 새 학생의 성적표가 `1 / 1`로 고정되지 않고, Google Sheets에 저장된 동일 시험 전체 학생을 기준으로 평균·중앙값·최고점·석차·문항별 정답률이 표시됩니다.

공개안전본에는 학생 기본 데이터가 없으므로 기존 학생들이 Google Sheets 또는 해당 교사 기기의 브라우저 기록에 존재해야 합니다. 기존 학생이 어느 곳에도 없다면 비교할 데이터가 없어 1명 기준이 정상입니다.
