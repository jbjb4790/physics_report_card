배포에 저장된 서버 주소를 자동으로 확인하고 있습니다.

Apps Script 주소는 GitHub 배포에서 자동 적용됩니다. 새 컴퓨터에서는 교사 PIN을 한 번 입력하거나, 기존 컴퓨터에서 만든 10분짜리 1회용 연결 링크를 열면 됩니다.
