학생별 성적표 링크 만들기

학교, 학생 이름, 1~20번 답안을 입력한 뒤 학생별 성적표 링크 생성을 누릅니다.

채점 규칙
정답 +5점, 오답 -1.25점, 미기입 0점입니다. 빈칸은 문항을 비우거나 붙여넣기에서 0, X, -로 입력할 수 있습니다. 엑셀·Google Sheets의 한 행을 그대로 복사하면 탭 사이의 빈 셀도 해당 문항의 미기입으로 보존됩니다.
학생에게 전달
생성된 링크는 학생마다 다릅니다. 링크를 복사해 학생에게 개인적으로 전달하세요. 결과 화면 오른쪽 위에서 Word 파일 저장과 PDF 저장·인쇄를 할 수 있습니다.
오답 동형 문제
틀리거나 비운 문항에는 같은 풀이 방식을 사용하는 새 5지선다 문제가 1개씩 나옵니다. 처음에는 정답과 풀이가 가려져 있습니다. 학생이 선택지를 고르는 순간 정오가 채점되고 정답과 해설이 공개되며, 다시 풀기로 초기화할 수 있습니다. 풀이 기록은 학생이 사용하는 기기의 브라우저에 저장됩니다.
답안 한 번에 입력
20개 번호를 공백·쉼표·슬래시로 구분해 붙여넣거나 CSV 입력 양식을 내려받아 여러 학생 기록을 가져올 수 있습니다.

저장 방식 선택

브라우저 저장
별도 설치 없이 바로 사용합니다. 현재 기기의 학생 기록으로 통계를 계산하고, 성적 데이터가 들어간 긴 링크를 만듭니다. 모든 학생 입력 후 기록의 열기를 다시 눌러야 최신 통계가 링크에 반영됩니다.
Google Sheets 저장
무작위 토큰으로 된 비교적 짧은 링크를 만듭니다. 학생이 링크를 열 때 Sheet의 최신 누적 통계와 이전 회차 결과를 불러옵니다. 여러 기기에서 입력할 때 적합합니다.

Google Sheets 누적 저장 설치

  1. Google 스프레드시트를 만들고 확장 프로그램 → Apps Script를 엽니다.
  2. 패키지의 apps-script/Code.gs 전체를 붙여넣습니다.
  3. 프로젝트 설정 → 스크립트 속성에 WRITE_KEY를 추가하고 교사만 아는 긴 비밀번호를 저장합니다.
  4. initializeSheet 함수를 한 번 실행해 권한을 승인합니다.
  5. 배포 → 새 배포 → 웹 앱에서 실행 사용자를 본인, 액세스 사용자를 학생이 열 수 있는 범위로 지정합니다. 로그인 없는 링크가 필요하면 익명 사용자 포함 권한이 필요합니다.
  6. 생성된 /exec URL을 입력 화면의 누적 저장 설정에 넣고 주소 저장·연결 확인을 누릅니다.
  7. 연결에 성공한 URL과 저장 방식은 이 브라우저의 localStorage에 저장됩니다. 같은 GitHub Pages 주소를 다시 열거나 사이트를 재배포해도 자동으로 불러와 서버 연결을 확인합니다.
  8. 누적 저장 방식 설정의 Google Sheets 저장 키 칸에 WRITE_KEY를 한 번 입력합니다. 이 교사 기기에 저장되어 이후 제출 때 다시 묻지 않습니다.

Apps Script 연결을 계속 유지하는 방법

같은 기기·브라우저
사이트에서 /exec 주소를 한 번 입력하면 즉시 저장됩니다. 다음 접속부터 저장 방식을 Google Sheets로 복원하고 자동으로 연결 상태를 확인합니다. 브라우저 데이터 삭제·시크릿 모드에서는 다시 입력해야 합니다.
다른 기기
다른 기기 설정 링크 복사를 눌러 만든 링크를 새 기기에서 한 번 열면 그 브라우저에도 같은 주소가 저장됩니다. Apps Script URL은 연결 주소이며 WRITE_KEY는 포함되지 않습니다.

모든 교사 기기에서 별도 입력 없이 자동 연결하려면 site/assets/config.js의 backendUrl 값에 Apps Script의 /exec 주소를 넣어 GitHub에 올립니다. 이 경우에도 WRITE_KEY는 코드나 GitHub 저장소에 넣지 않습니다.

이전 회차 분석

같은 학교·이름으로 저장된 기록은 입력한 순서가 아니라 회차 번호 순서로 연결됩니다. 예를 들어 5회 결과를 먼저 입력하고 4회 결과를 나중에 입력해도, 기존 5회 서버 링크를 다시 열거나 상단의 최신 분석을 누르면 4회가 이전 회차 분석에 포함됩니다. 반대로 4회 리포트에는 미래 회차인 5회가 표시되지 않습니다. 예전 #report=... 링크에 서버 토큰이 남아 있으면 열 때 자동으로 최신 서버 링크로 전환됩니다. 현재 패키지에는 1회~10회 시험·해설이 등록되어 있습니다.

개인정보와 링크 보안
성적표 링크는 계정 로그인 문서가 아니라 링크 소지자가 볼 수 있는 방식입니다. 공개 게시판에 링크를 올리지 마세요. 이 공개 배포용 버전은 assets/seed-records.js를 빈 데이터로 구성하여 실제 학생 이름과 답안을 포함하지 않습니다. 실제 성적은 교사용 화면에서 입력하거나 Google Sheets 모드로 저장하세요. Google Sheets 저장 키는 코드나 저장소에 넣지 마세요. 키는 교사 기기 브라우저에 저장되므로 공용 컴퓨터에서는 작업 후 반드시 지우세요. 동명이인이 있을 수 있다면 이름에 반·번호 또는 내부 식별 문자를 함께 입력하세요.

시험 자료 해설 메모

1회 7번은 공식 정답표 ⑤를 적용하며, 유도 전류 방향 관련 해설 문구의 불일치를 성적표에 표시했습니다. 2회 3번은 공식 해설에서 추와 수레의 질량 기호가 식과 설명 사이에 뒤바뀐 표기가 있어 표준식으로 정리했으며 공식 정답 ②는 그대로 유지합니다. 3회는 공식 정답표 ④,⑤,③,④,①,④,③,③,①,②,④,③,④,⑤,②,②,④,②,②,④를 적용했습니다. 9회 7번과 10회 18번은 공식 정답표와 문항·해설의 해석이 맞지 않아 공식 키로 채점하면서 리포트에 원문 확인 메모를 표시합니다.

다른 컴퓨터에서 학생 기록 확인하기

학생 입력 결과는 Google Sheets를 원본으로 저장합니다. 새 컴퓨터에서는 누적 저장 방식 설정에 같은 Google Sheets 저장 키를 처음 한 번 입력한 뒤 서버 기록 새로고침을 누르세요. 이후에는 사이트를 열거나 다시 활성화할 때 서버 학생 목록을 자동으로 동기화합니다.

이전 버전에서 특정 컴퓨터에만 남은 기록은 그 컴퓨터의 학생 기록 영역에서 이 기기 기록 서버로 올리기를 눌러 이전할 수 있습니다.
