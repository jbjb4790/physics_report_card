학생별 성적표 링크 만들기

학교, 학생 이름, 1~20번 답안을 입력한 뒤 학생별 성적표 링크 생성을 누릅니다.

채점 규칙
정답 +5점, 오답 -1.25점, 미기입 0점입니다. 빈칸은 답안 버튼의 ‘빈칸’ 또는 붙여넣기에서 0, X, -로 입력할 수 있습니다.
학생에게 전달
생성된 링크는 학생마다 다릅니다. 링크를 복사해 학생에게 개인적으로 전달하세요. 결과 화면 오른쪽 위에서 Word 파일 저장과 PDF 저장·인쇄를 할 수 있습니다.
오답 동형 문제
틀리거나 비운 문항에는 같은 풀이 방식을 사용하는 새 5지선다 문제가 1개씩 나옵니다. 처음에는 정답과 풀이가 가려져 있습니다. 학생이 선택지를 고르는 순간 정오가 채점되고 정답과 해설이 공개되며, 다시 풀기로 초기화할 수 있습니다. 풀이 기록은 학생이 사용하는 기기의 브라우저에 저장됩니다.
답안 한 번에 입력
20개 번호를 공백·쉼표·슬래시로 구분해 붙여넣거나 CSV 입력 양식을 내려받아 여러 학생 기록을 가져올 수 있습니다.

저장 방식 선택

브라우저 저장
별도 설치 없이 바로 사용합니다. 현재 기기의 학생 기록으로 통계를 계산하고, 성적 데이터가 들어간 긴 링크를 만듭니다. 모든 학생 입력 후 기록의 열기를 다시 눌러야 최신 통계가 링크에 반영됩니다.
Google Sheets 저장
무작위 토큰으로 된 비교적 짧은 링크를 만듭니다. 학생이 링크를 열 때 Sheet의 최신 누적 통계와 이전 회차 결과를 불러옵니다. 여러 기기에서 입력할 때 적합합니다.

Google Sheets 누적 저장 설치

  1. Google 스프레드시트를 만들고 확장 프로그램 → Apps Script를 엽니다.
  2. 패키지의 apps-script/Code.gs 전체를 붙여넣습니다.
  3. 프로젝트 설정 → 스크립트 속성에 WRITE_KEY를 추가하고 교사만 아는 긴 비밀번호를 저장합니다.
  4. initializeSheet 함수를 한 번 실행해 권한을 승인합니다.
  5. 배포 → 새 배포 → 웹 앱에서 실행 사용자를 본인, 액세스 사용자를 학생이 열 수 있는 범위로 지정합니다. 로그인 없는 링크가 필요하면 익명 사용자 포함 권한이 필요합니다.
  6. 생성된 /exec URL을 입력 화면의 누적 저장 설정에 넣고 서버 연결 확인을 누릅니다.
  7. 첫 학생 저장 때 WRITE_KEY를 입력합니다. 키는 현재 탭에만 임시 보관됩니다.

이전 회차 분석

새 회차 시험을 assets/exam-data.js와 Apps Script의 EXAMS에 같은 시험 ID로 추가한 뒤, 같은 학교·이름으로 입력하면 이전 회차 점수와 단원별 변화를 자동으로 연결합니다. 현재 패키지에는 1회~10회 시험·해설이 등록되어 있으며, 1회~5회 학생 결과 225개가 기본 데이터로 포함되어 있습니다. 같은 학교·이름으로 입력하면 회차별 변화가 자동으로 연결됩니다.

개인정보와 링크 보안
성적표 링크는 계정 로그인 문서가 아니라 링크 소지자가 볼 수 있는 방식입니다. 공개 게시판에 링크를 올리지 마세요. 이 배포본은 요청에 따라 1~5회 기존 학생 이름과 답안을 assets/seed-records.js에 포함하므로 공개 GitHub Pages에서는 해당 데이터도 내려받을 수 있습니다. 실제 운영 전 공개 범위를 확인하고, 공개 사이트라면 기본 데이터를 제거한 뒤 Google Sheets 모드로 이전하세요. Google Sheets 저장 키는 코드나 저장소에 넣지 마세요. 동명이인이 있을 수 있다면 이름에 반·번호 또는 내부 식별 문자를 함께 입력하세요.

시험 자료 해설 메모

1회 7번은 공식 정답표 ⑤를 적용하며, 유도 전류 방향 관련 해설 문구의 불일치를 성적표에 표시했습니다. 2회 3번은 공식 해설에서 추와 수레의 질량 기호가 식과 설명 사이에 뒤바뀐 표기가 있어 표준식으로 정리했으며 공식 정답 ②는 그대로 유지합니다. 3회는 공식 정답표 ④,⑤,③,④,①,④,③,③,①,②,④,③,④,⑤,②,②,④,②,②,④를 적용했습니다. 9회 7번과 10회 18번은 공식 정답표와 문항·해설의 해석이 맞지 않아 공식 키로 채점하면서 리포트에 원문 확인 메모를 표시합니다.
