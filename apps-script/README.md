# Google Sheets + Apps Script 누적 저장 설치

이 폴더의 `Code.gs`는 GitHub Pages 입력 화면이 Google Sheet에 학생 결과를 저장하고, 학생별 무작위 토큰 링크로 결과를 불러오게 하는 JSONP 웹 앱입니다.

## 1. 스프레드시트와 스크립트 준비

1. 새 Google 스프레드시트를 만듭니다.
2. 스프레드시트의 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고 이 폴더의 `Code.gs` 전체를 붙여넣습니다.
4. 필요하다면 프로젝트 설정에서 매니페스트 파일 표시를 켜고 `appsscript.json`도 반영합니다.

## 2. 스크립트 속성 설정

Apps Script 왼쪽 메뉴의 **프로젝트 설정 → 스크립트 속성**에서 다음 값을 추가합니다.

- `WRITE_KEY` — 필수. 교사만 아는 긴 저장·삭제 비밀번호입니다. 예측하기 어려운 값으로 정하고 GitHub 코드에는 넣지 않습니다.
- `SPREADSHEET_ID` — 선택. 스프레드시트에 연결된 스크립트라면 생략합니다. 독립형 스크립트를 사용하는 경우 대상 Sheet URL의 `/d/`와 `/edit` 사이 ID를 입력합니다.

현재 프런트엔드는 `ADMIN_KEY`가 아니라 **`WRITE_KEY`**를 사용합니다.

## 3. 시트 초기화

1. 함수 선택 메뉴에서 `initializeSheet`를 선택합니다.
2. **실행**을 누르고 Google Sheets 접근 권한을 승인합니다.
3. 스프레드시트에 `Reports` 시트와 헤더가 생성되었는지 확인합니다.

이 단계는 생략해도 첫 저장 때 자동 생성되지만, 배포 전 권한과 Sheet 연결을 점검하기 위해 먼저 실행하는 편이 좋습니다.

## 4. 웹 앱 배포

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 유형에서 **웹 앱**을 선택합니다.
3. 실행 사용자는 **나/배포한 사용자**로 지정합니다.
4. 학생이 로그인 없이 결과를 열어야 한다면 액세스 사용자를 **모든 사용자·익명 사용자 포함**으로 지정합니다.
5. 배포 후 표시되는 `https://script.google.com/macros/s/.../exec` 주소를 복사합니다.

조직 정책상 익명 사용자를 선택할 수 없다면 외부 학생은 서버 모드 링크를 열 수 없습니다. 이 경우 브라우저 저장 모드를 사용하거나 조직 인증에 맞는 백엔드를 구성하세요.

## 5. 사이트에 연결

1. GitHub Pages의 교사용 입력 화면을 엽니다.
2. **누적 저장 방식 설정**을 펼칩니다.
3. 저장 방식을 **Google Sheets + Apps Script**로 선택합니다.
4. 배포된 `/exec` URL을 입력합니다.
5. **서버 연결 확인**을 눌러 성공 메시지를 확인합니다.
6. 학생 결과를 처음 저장할 때 나타나는 창에 `WRITE_KEY` 값을 입력합니다.

저장 키는 브라우저 탭의 `sessionStorage`에만 임시 저장되며 탭을 닫으면 사라집니다. 입력 화면의 **저장 키 지우기**로 즉시 삭제할 수도 있습니다.

## 데이터와 링크 구조

`Reports` 시트에서 학생별·시험별 최신 기록을 한 행으로 관리합니다.

- 동일 학생 판정: 공백을 제거하고 소문자화한 **학교 + 이름**
- 동일 시험 판정: `ExamId`
- 같은 학생·시험을 다시 저장하면 기존 토큰을 유지하고 행을 갱신
- 다른 회차는 별도 행으로 저장하고 이전 회차 분석에 연결
- 학생 링크에는 `/exec` 주소와 32자리 무작위 토큰만 포함
- `get` 요청은 토큰을 가진 사람이 해당 결과를 읽을 수 있음
- `save`, `delete`, `list` 요청은 `WRITE_KEY` 필요

학생 링크는 로그인 계정이 아니라 토큰 소지자를 인증하는 방식입니다. 공개 게시판에 게시하지 마세요.

## 코드 수정 후 재배포

Apps Script 코드를 수정한 뒤 단순히 저장하는 것만으로 기존 `/exec` 배포가 갱신되지 않을 수 있습니다.

1. **배포 → 배포 관리**를 엽니다.
2. 기존 웹 앱 배포의 편집 아이콘을 누릅니다.
3. 새 버전을 선택하고 다시 배포합니다.
4. 배포 URL이 유지되는지 확인한 뒤 사이트의 **서버 연결 확인**을 다시 실행합니다.

## 7번 정답

서버의 1회 정답표도 7번을 **⑤**로 저장했습니다. 첨부 해설 본문의 ‘시계 방향’ 문구는 그림·보기·공식 정답표와 맞지 않는 오기이며, 사이트 설명은 시계 반대 방향으로 교정되어 있습니다.

## 등록된 시험

현재 `Code.gs`의 `EXAMS`에는 다음 10개 회차가 등록되어 있습니다.

- `tpl-mid-01` — TPL 중급 모의고사 1회
- `tpl-mid-02` — TPL 중급 모의고사 2회
- `tpl-mid-03` — TPL 중급 모의고사 3회
- `tpl-mid-04` — TPL 중급 모의고사 4회
- `tpl-mid-05` — TPL 중급 모의고사 5회
- `tpl-mid-06` — TPL 중급 모의고사 6회
- `tpl-mid-07` — TPL 중급 모의고사 7회
- `tpl-mid-08` — TPL 중급 모의고사 8회
- `tpl-mid-09` — TPL 중급 모의고사 9회
- `tpl-mid-10` — TPL 중급 모의고사 10회

3회 정답표는 `④ ⑤ ③ ④ ① ④ ③ ③ ① ② ④ ③ ④ ⑤ ② ② ④ ② ② ④`이며, 서버에서도 정답 +5점, 오답 -1.25점, 미기입 0점으로 채점합니다. 학교와 이름이 같은 학생의 1~10회 기록은 회차 순서대로 이전 성적 분석에 연결됩니다.
